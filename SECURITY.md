# Security Policy

CyberArk takes the security of our software products and services seriously,
including all source code repositories managed through our GitHub organization.

## Reporting a Vulnerability

If you believe you have found a security vulnerability in this repository,
please report it to us privately. **Do not report security vulnerabilities
through public GitHub issues, discussions, or pull requests.**

Instead, email **product_security@cyberark.com** with the details.

Please include as much of the following information as possible to help us
better understand and resolve the issue:

- The type of issue and the affected component (e.g. chart template, container
  image, configuration).
- The chart version(s) affected.
- Step-by-step instructions to reproduce the issue.
- Proof-of-concept or exploit code, if available.
- The impact of the issue, including how an attacker might exploit it.

## Supported Versions

Security fixes are applied to the latest released version of the
`sia-k8s-connector` chart. We recommend always running the most recent version.

## Response Process

After you submit a report, we will acknowledge receipt and work with you to
understand and validate the issue. We ask that you give us a reasonable amount
of time to investigate and address the vulnerability before any public
disclosure.
